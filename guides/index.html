Un navigateur qui travaille pour vous

Un userscript est un programme JavaScript qui s’exécute sur les pages prévues par son auteur. Il peut ajouter un bouton, traduire un texte ou améliorer une interface. Un gestionnaire de scripts se charge de les installer et de les lancer.

Un exemple concret

Sur une conversation avec une IA, un userscript peut ajouter un bouton d’export pour enregistrer le contenu dans un format choisi. Sur une autre page, il peut traduire une sélection de texte.

Commencer en trois étapes

  1. Installer un gestionnaire

    Choisissez un gestionnaire compatible avec votre navigateur, par exemple Tampermonkey ou Violentmonkey, depuis sa source officielle.

    Tampermonkey ↗Violentmonkey ↗

  2. Choisir un script

    Lisez la description, les sites concernés et les avis. Sur Greasy Fork, ouvrez la page du script, puis cliquez sur le bouton d’installation.

    Greasy Fork ↗Découvrir mes projets

  3. Confirmer et utiliser

    Vérifiez les informations présentées par votre gestionnaire et confirmez. Rechargez la page concernée si nécessaire ; vous pouvez ensuite désactiver ou supprimer le script depuis le gestionnaire.

Selon le navigateur et le gestionnaire, une autorisation supplémentaire peut être nécessaire pour exécuter les scripts. Consultez les instructions de votre gestionnaire.

Un mot sur la confiance

Un userscript peut accéder au contenu des pages sur lesquelles il s’exécute. Installez seulement des scripts dont vous comprenez l’usage et dont vous faites confiance à la source ; examinez les autorisations et le code si vous le pouvez.

Si le script ne fonctionne pas

Vérifiez que le script est activé dans votre gestionnaire, que la page correspond aux sites pris en charge, puis rechargez-la. Certains navigateurs demandent une autorisation supplémentaire.
